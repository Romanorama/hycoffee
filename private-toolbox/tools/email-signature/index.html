E-Mail Signatur

Erstelle eine konsistente HyCoffee E-Mail-Signatur mit Logo und Markenfarben. Felder ausfüllen, Vorschau prüfen und als HTML-Datei herunterladen.

Daten

Logo wird beim Download eingebettet (Base64) — die Datei ist eigenständig.

Vorschau

Signatur in das E-Mail-Programm einbinden

Apple Mail (macOS)

  1. HTML-Datei im Browser (Safari) öffnen.
  2. Inhalt mit ⌘ + A markieren, ⌘ + C kopieren.
  3. In Mail: Mail → Einstellungen → Signaturen.
  4. Account wählen, + klicken und Signatur einfügen mit ⌘ + V.
  5. Häkchen bei „Standardschriftart immer verwenden“ entfernen.

Outlook (Windows / Mac)

  1. HTML-Datei im Browser öffnen.
  2. Inhalt markieren und kopieren.
  3. Outlook öffnen: Datei → Optionen → E-Mail → Signaturen… (Win) bzw. Outlook → Einstellungen → Signaturen (Mac).
  4. Neue Signatur anlegen, in das Feld einfügen und speichern.
  5. Unter „Neue Nachrichten“ und „Antworten/Weiterleitungen“ als Standard auswählen.

Gmail (Web)

  1. HTML-Datei im Browser öffnen, Inhalt kopieren.
  2. In Gmail: Einstellungen (Zahnrad) → Alle Einstellungen anzeigen.
  3. Tab „Allgemein“ → Abschnitt „Signatur“ → „Neu erstellen“.
  4. Signatur einfügen, einen Namen vergeben, speichern.
  5. Unten unter „Signaturstandards“ als Standard für neue Mails & Antworten setzen.

Thunderbird

  1. HTML-Datei lokal speichern (z. B. unter ~/Dokumente/Signatur).
  2. In Thunderbird: Konten-Einstellungen öffnen, Account auswählen.
  3. Häkchen bei „Signatur aus einer Datei anhängen“ setzen.
  4. Auf Auswählen… klicken und die HTML-Datei laden.
  5. Speichern — Logo wird über die Base64-Einbettung mitgeschickt.

iOS / iPadOS Mail

  1. HTML-Datei per AirDrop oder Mail an dich selbst senden.
  2. Mail öffnen, Inhalt der Signatur per Antippen & Halten markieren und kopieren.
  3. Einstellungen → Mail → Signatur öffnen.
  4. Vorhandenen Text löschen, Signatur einfügen.
  5. Auf „Schütteln und Rückgängig“ achten — nicht erneut auf „Markierter Text“ tippen, sonst gehen Stile verloren.

Hinweise

  1. Logo wird beim Download als Base64 in die HTML eingebettet — es funktioniert offline und ohne Hosting.
  2. E-Mail-Clients ignorieren benutzerdefinierte Schriften (HAL Timezone). Es werden Web-Safe-Fonts verwendet, die im Stil dem CD nahekommen.
  3. Bei Outlook (alte Versionen) ggf. Logo-Größe halbieren, falls es zu groß angezeigt wird.
  4. Farbtreue ist garantiert (Inline-Styles, kein externes CSS).
